# Contributing

**TPT Media QC** is the commercial application tier of the TPT Apps family
and is not currently open to external code contributions.

Found a bug or have a feature request? Please open an issue describing:

- What you expected to happen and what happened instead.
- Steps to reproduce, including the media file characteristics if relevant
  (container, codec, resolution) — avoid attaching copyrighted or sensitive
  media.
- Your platform and application version.
